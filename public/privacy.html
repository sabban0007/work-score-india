Privacy Policy — Work Score India

Last updated: September 2026

Work Score India ("we", "the app") is a platform that lets workers create a digital work profile and lets employers search for verified workers.

What we collect

DataWho provides itWhy
Name, mobile number, cityWorker (at registration)To identify and contact the worker
Skill, experience, previous employer + mobileWorkerTo build the work profile and calculate the Work Score
Aadhaar photo (optional)WorkerFor identity verification by the admin only
Ratings, verification status, job historyAdminTo keep the Work Score accurate

Who can see this data

  • Basic profile info (name, skill, city, experience, Work Score) is visible to anyone using the Employer search — this is the core purpose of the app.
  • The Aadhaar photo is visible only to the platform admin, and only through an authenticated login. It is never shared publicly or with any third party.

Where the data is stored

All data is stored using Google Firebase (Firestore Database, Firebase Storage, Firebase Authentication), hosted on Google Cloud infrastructure. We do not sell or share your data with advertisers.

Your rights

  • You can ask us to correct or delete your profile at any time by contacting the admin.
  • A worker's mobile number is used as their unique ID — registering again with the same number is not possible; contact the admin for corrections.

Contact

For any privacy question or data removal request, contact the platform admin directly.
